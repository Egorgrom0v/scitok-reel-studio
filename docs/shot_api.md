# Как писать шот

Шот — тело JS-функции, которая строит сцену 1080×1000 и раскладывает анимацию на таймлайне GSAP `tl`.
Движок перематывает `tl` покадрово и снимает кадры, поэтому всё должно зависеть **только от времени**:
никаких `Math.random`, `Date`, `setTimeout`, `requestAnimationFrame` (случайность — `rng(seed)` из `kit/core.js`).

## API движка (уже загружено)

Время и данные: `D` — длина шота, с; `S.words` — слова фразы `[{w, t0, t1}]` от начала шота;
`wt('слово', n=0)` — время слова или `null`; `clampT(t)`; `tl.to / fromTo / set(el, vars, t)`.

Элементы (`parent` — контейнер, по умолчанию сцена):
- `el(tag, cls, css, html, parent)` — DOM-элемент (позиция `absolute` задаётся в css);
- `Tx(text, x, y, {size, w, color, align: 'l'|'r', wrap, width, talign, t, parent})` — текст Inter, (x, y) — центр (или левый/правый край при `align`);
- `Kc(x, y, w, h, t, {r, bg, border, bw})` — белая карточка, (x, y) — левый верхний угол;
- `chip(text, x, y, t, {tone: 'blue'|'green'|'red'|'gray'|'dark', size, h, px, align: 'l', parent})` — плашка;
- `eyebrow(text, y, t, {x})` — надстрочник капсом;
- `num(value, x, y, t, {size, color, dec, suf, align, dur})` — число со счётчиком;
- `vbarA(x, base, v, k, t, {w, dec, label, color})` — столбик со значением и подписью;
- `svgLayer(parent)`, `sv(svg, tag, attrs)` — SVG; `lineA(svg, x1, y1, x2, y2, t, {color, w, dur, dash})` — линия рисуется;
  `drawOn(path, t, d)`; `arrowHead(svg, path, color, size)`;
- `docCard(cropName, {cy, maxW, maxH, frame: true, at, hlAt, zoom})` — кроп статьи (имена кропов — `reel/shot_plan.orig.json` → `crops`);
- движение: `inA(el, t, {dy})` — вход, `outA(el, t)` — выход, `popA(el, t)` — «поп», `show(el, t)`;
- `exitAll()` — всё мягко уходит в конце шота (последняя строка каждого шота);
- звук: `sfx(name, t, {gain: 0.05–0.1, align: 'end'})`, имена — файлы `sfx/`: `Select`, `Select_3`, `Click_UI Buttons_2`,
  `Mechanical_Click_Button_2`, `Cartoon_Pop`, `Beep_8`, `Whoosh_6`, `Whoosh`, `Reversed Whoosh`, `Riser_4`,
  `Boom, Impact_2`, `Boom, Impact_Stinger_2`, `Sci_Fi`, `Game_2`, `тррр_короткий_4`, `тррр_длинный_4`.
- цвета `A`: `ink`, `sub`, `faint`, `line`, `soft`, `bg`, `blue`, `green`, `red`, `amber`; `A.tint(цвет, 0..1)` — полупрозрачный.

## Наборы `kit/`

`core.js` (всегда): `Wv`, `hide0`, `rng`, `amberChip`, `toneChip`, `mark` (✓/✗), `stamp` («БРАК»), `arrowAt`,
`ringPulse`, `bubble` (сообщение по словам), `spanXY`, `hlWord`, `postCard` (пост с форума), `slot` / `ring` / `swapV`
(ячейки со значением), `actor` (тёмная таблетка-исполнитель), `person` (абстрактный человек), `envelope`,
`letterGrid`, `dbCyl` (база-цилиндр), `dots` (сетка точек «N из M»), `flipBadge` (плашка «было → стало»).

`chem.js`: `Mol` / `molAt` (молекула из атомов и связей, атомы двигаются, связи тянутся, `'ts'` — частичная
связь пунктиром), `SP` (несколько готовых форм), `miniMol` (молекула-значок), `eProfile` (энергетический профиль
с перевалом), `along` / `ballOn` (шарик катится по пути).

Подробности и параметры — комментарии в самих файлах. Свои помощники для одного ролика — `work/_local.js`.

## Ловушки (каждая уже стоила кому-то времени)

1. **`chip(..., null)` и `Kc(..., null)` видны с первого кадра** — движок делает `show(e, 0)`. Если элемент
   появится своей анимацией позже, оберни: `hide0(chip(...))`.
2. **`arrowHead` виден сразу**, даже если линия рисуется позже — используй `arrowAt(svg, path, col, size, t)`.
3. **SVG, созданный до карточки `Kc`, оказывается под ней.** Рисуешь в карточке — создай слой после неё и
   подними: `const s = svgLayer(); s.style.zIndex = 5;` (или `svgLayer(card)` — координаты внутри карточки).
4. **DOM-проверка не понимает анимаций и обрезки**:
   - текст, который въезжает со `scale` < 1, она меряет мелким — у текстовых плашек анимируй `y` и `opacity`;
   - две грани переворота, стопка карточек, текст под `overflow: hidden` — для неё «наложение» / «обрезка»:
     прячь невидимые части `opacity: 0`, вместо прокрутки в окне меняй текст строк через `onUpdate`.
5. **Позиция слова** в пузыре — `spanXY(span, bubbleX, bubbleY)` (через `offsetLeft`), не `getBoundingClientRect`
   (на стейдже работает зум камеры).
6. **Индексы слов** — по `text.split(' ')`; «40 %» — это два слова. Проверь индексы, прежде чем подсвечивать.
7. **`tl.call` не используй** для смены состояния: при перемотке назад он не откатывается. Меняй через
   `tl.to(obj, {..., onUpdate})` с состоянием, которое вычисляется из прогресса.
8. Относительные значения (`x: '+=200'`) работают, но считаются в момент первого рендера твина.
9. Ширина кириллицы жирным ≈ 0,55 × размер шрифта на букву. Длинная плашка у края — посчитай, влезет ли.
10. На итоговом видео стейдж немного увеличен (`stage_zoom` 1,12): у самых краёв кадр подрезается — держи
    важное в безопасной зоне.

## Хороший шот — это

- одна метафора, крупно, мало текста; зритель без звука понимает, что произошло;
- первый элемент на экране в первые 0,2–0,3 с; главное событие — на слове (`Wv`);
- движение каждые 1–1,5 с: появление, перенос, подсветка, счётчик, перекрашивание;
- звук на событиях (тихо, `gain` 0,04–0,09);
- в конце `exitAll()`.
