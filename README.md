# SciTok Reel Studio

Сделай свой ролик SciTok по-настоящему крутым — с помощью своего ИИ-агента.

SciTok превращает научную статью в вертикальное видео: сценарий, озвучка, говорящий
аватар, субтитры. Бесплатная версия экономит на анимации: сцены собираются из шаблонов, бывают однообразными,
а надписи иногда налезают друг на друга. Этот репозиторий — мастерская, в которой твой агент (Claude Code
или другой агент с доступом к терминалу) перепишет анимацию каждой сцены в живые «геройские» шоты:
молекулы, которые перестраиваются, письма со штампами, базы данных, перевалы энергии — и соберёт ролик заново.

Голос, аватар, субтитры и сценарий остаются твоими: меняется только верхняя часть кадра. Пересборка идёт у тебя
на компьютере, ключи и видеокарта не нужны.

## Как пользоваться

1. На странице готового ролика нажми **«Скачать архив»** — получишь `research-reels-<id>-debug.zip`.
2. Открой Claude Code (или другого ИИ-агента с доступом к терминалу) и вставь в чат:
   ```
   git clone https://github.com/Egorgrom0v/scitok-reel-studio.git
   ```
3. В том же чате прикрепи скачанный архив как папку (Add folder) — или укажи путь к нему — и напиши:
   > Доработай мой ролик из прикреплённой папки по инструкции из scitok-reel-studio: сделай анимацию
   > сцен интереснее и понятнее, голос и аватар не трогай.

Агент найдёт инструкцию (`.claude/skills/scitok-reel/SKILL.md`; для других агентов — `AGENTS.md`), поставит
пакеты, разберёт ролик, перепишет сцены, проверит кадры и отдаст `videos/<имя>/out/reel_<имя>.mp4`.
Не клонируй в папку, которую синхронизирует iCloud (Документы, Рабочий стол): рендер там может зависнуть.

Дальше можно просить правки словами: «в сцене 7 покажи молекулу крупнее», «сделай два варианта финала».

Нужно: macOS или Linux, `python3`, `node` ≥ 18, `ffmpeg`. Агент должен уметь запускать команды в терминале:
Claude Code, Codex CLI, Cursor Agent и т. п. Обычный чат без терминала ролик не соберёт.

## Что внутри

- `engine/` — движок рендера SciTok (план шотов → кадры через Chromium → звук → сборка с аватаром и субтитрами);
- `kit/` — наборы помощников для своих шотов и сборщик плана `apply.py`;
- `examples/` — проверенные шоты из готовых роликов;
- `scripts/` — `import.py` (взять архив), `words.py` (слова и время), `check.py` (проверка вёрстки),
  `stills.py` (кадры для просмотра), `build.sh` (собрать mp4);
- `docs/shot_api.md` — как писать шот; `.claude/skills/scitok-reel/SKILL.md` — инструкция для агента.

Вручную, без агента:

```bash
bash scripts/setup.sh
python3 scripts/import.py ~/Downloads/research-reels-<id>-debug.zip myreel
python3 scripts/words.py videos/myreel
cp examples/status_flip.js videos/myreel/work/s14.js     # свой шот для сцены s14
python3 scripts/check.py videos/myreel && python3 scripts/stills.py videos/myreel
bash scripts/build.sh videos/myreel
```
