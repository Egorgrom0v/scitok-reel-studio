# Инструкция для ИИ-агента

Этот репозиторий — мастерская для доработки роликов SciTok. Когда человек даёт архив или папку ролика
(`research-reels-<job_id>-debug`) и просит сделать видео лучше, следуй `.claude/skills/scitok-reel/SKILL.md`
от начала до конца: подготовка → импорт → план сцен → свои шоты → проверка кадров → сборка mp4.
Перед первым шотом прочитай `docs/shot_api.md` и несколько файлов из `examples/`.
