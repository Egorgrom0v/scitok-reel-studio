# SciTok engine — справочник

Движок собирает вертикальный ролик 1080×1920 @30 fps из папки видео. Раскладка **v8**: стейдж (анимация) сверху, увеличен в 1,12 раза; аватар на всю ширину снизу (900 px); субтитры на стыке анимации и аватара; кропы статьи без рамок; светлая тема. Шапки, кикеров, бейджей и подписи статьи на экране нет. Он один на все ролики; всё, что относится к конкретной статье, лежит в `videos/<slug>/`.

## Команды (из корня кита)

```bash
bash setup.sh                                   # один раз: RHVoice, ffmpeg, pymupdf, gsap, playwright, шрифты
bash engine/build.sh videos/<slug>              # полный прогон
bash engine/build.sh videos/<slug> --from stage # перерендерить шоты после правки shots.js (и всё после них)
VIDEO=videos/<slug> python3 engine/tts.py       # только озвучка + тайминги (быстро: проверить длину и якоря)
VIDEO=videos/<slug> node engine/render_stage.js 's07|s12' --still   # превью: PNG середины и конца шотов → build/stills/
VIDEO=videos/<slug> PAGES=2 node engine/render_stage.js            # меньше параллельных страниц, если мало памяти
bash setup.sh --asr && VIDEO=videos/<slug> node engine/asr_check.mjs s03 s12 s20   # офлайн-сверка речи
```

### Внешняя озвучка (ElevenLabs и т. п.)
Положи в папку видео `voice.mp3` (или `voice.wav`; либо укажи путь в `video.json` → `"voice_file"`) — **одним файлом на весь ролик**, текст = поля `subtitle` по порядку. Тогда `tts.py` не вызывает RHVoice:
- распознаёт файл офлайн с таймингами слов (`asr_words.mjs`, нужен `bash setup.sh --asr`, ~3 мин на 2 минуты звука);
- сопоставляет слова распознавания со словами субтитров;
- режет файл на сцены по паузам.

Шоты и субтитры встают на реальные тайминги речи. Строка `aligned N/M words` должна быть ≥ 90 %, иначе текст озвучки разошёлся с `subtitle`. Поле `tts` в этом режиме не используется. Поменял озвучку — `bash engine/build.sh videos/<slug>` целиком (кэш распознавания обновится сам).

### Голос и аватар из бэкенда (продакшн)
`voice/<scene>.wav` на каждую сцену + `alignment.json` (Fish + WhisperX) — режим `voice_mode: scenes`, без RHVoice и ASR. Один трек аватара под этот голос — `avatar_mode: sync`, `avatar_file`. Подробно — `services/reel_engine/README.md`.

Шаги `build.sh`: `tts → fonts → crops → stage → audio → compose → sheet → metrics` (`metrics.json` — числа для проверки качества). Рендер стейджа — самый долгий (~3,5 мин на 47 шотов при 4 страницах).

## Папка видео

```
videos/<slug>/
  video.json        мета и настройки (ниже)
  storyboard.json   сцены и шоты
  crops.py          какие места PDF вырезать и подсветить
  shots.js          анимации шотов: SH.<scene>_<n> = () => {...}
  paper.pdf         статья (имя любое; или путь в video.json "pdf")
  build/            всё промежуточное (не коммитить)
  <output>.mp4, contact_sheet.jpg     результат
```

### video.json
```json
{
 "slug": "alphafold", "output": "alphafold_wide.mp4",
 "paper": {"title": "...", "arxiv_or_doi": "...", "year": 2021, "field": "структурная биология", "license": "CC BY 4.0"},
 "audience": "wide | student | specialist",
 "pdf": "paper.pdf",
 "voice": "aleksandr-hq", "tts_rate": 145,
 "spoken_syllables": {"AlphaFold": 4, "CASP": 2},
 "theme": "light", "subtitles": "seam", "stage_zoom": 1.12, "avatar_h": 900,
 "xfade": [],
 "avatar_dir": "../../avatar",
 "music_db_below_voice": 20
}
```
`spoken_syllables` — сколько слогов звучит у латинских слов, аббревиатур и чисел цифрами (нужно для таймингов слов, у RHVoice их нет). `theme`: `light` (по умолчанию) или `dark`. `subtitles`: `seam` (по умолчанию, на стыке анимации и аватара), `avatar` (внизу) или `off`. `shots_theme: "dark"` — только для старых `shots.js`, написанных под тёмную тему: движок сам перекрасит их захардкоженные цвета. Новые ролики пишутся сразу через `COL.*`, без этого флага. `chrome_ui: true` возвращает кикеры и уголки на стейдже (старый вид).

### storyboard.json
Массив сцен. Одна сцена = одна фраза диктора.
```json
{"scene": "s07", "beat": "ПОВОРОТ",
 "subtitle": "И тут один из авторов, Якоб Ушкорайт, предложил: давайте выкинем очередь.",
 "tts": "И тут один из авторов, Якоб Ушкорайт, предложил: давайте выкинем очередь.",
 "accent": "выкинем",
 "claims": [{"text": "Jakob proposed replacing RNNs with self-attention", "source": "paper p.1 footnote"}],
 "shots": [
   {"share": 0.55, "source": "СТАТЬЯ", "visual": "сноска стр. 1, подсвечено «Jakob proposed…»", "anchor_word": "Ушкорайт",
    "badge": "ИЗ СТАТЬИ", "note": "сноска · стр. 1 статьи", "sfx": "riser к концу"},
   {"share": 0.45, "source": "КОД", "visual": "очередь слов перечёркивается и рассыпается", "anchor_word": "выкинем",
    "badge": "СХЕМА", "sfx": "impact"}]}
```
- `beat`: ХУК · АТРИБУЦИЯ · ПРОБЛЕМА · ПОВОРОТ · МЕХАНИЗМ · ПРУФ · ЭСКАЛАЦИЯ · ОГРАНИЧЕНИЕ · КОЛЬЦО · CTA. В битах ПРОБЛЕМА и ОГРАНИЧЕНИЕ акцентное слово в субтитрах красное, в остальных синее.
- `subtitle` — что видит зритель. `tts` — что читает голос: латиница транслитерирована («ChatGPT» → «чат джи-пи-ти»), падежи согласованы («в Гугле»), тире → запятые. **Число слов в `subtitle` определяет тайминги**, `tts` на них не влияет.
- `accent` — ровно одно слово из `subtitle`.
- `share` шотов сцены в сумме = 1. `anchor_word` — слово из **этой** сцены, на нём появляется главный элемент шота. Если якорь выпадает за границы шота, `tts.py` предупредит — переставь шоты или поменяй доли.
- `badge`: ИЗМЕРЕНО · ИЗ СТАТЬИ · СХЕМА · ВНЕ СТАТЬИ · «—». `note` — пояснение. На экране в v8 не показываются, нужны для отчёта и проверки честности.
- `sfx`: whoosh · deep whoosh · pop (на якоре) · impact (на якоре) · riser к концу · none (тихая склейка) · «—» (тихий whoosh по умолчанию).
- ID шота в `shots.js` = `<scene>_<номер с 1>`: `s07_1`, `s07_2`.

### crops.py
Выполняется движком с готовыми помощниками. Координаты — пункты PDF (72 на дюйм), страницы с 1.
```python
crop("p1_page", 1, (0, 0, 612, 792), [find(1, "Highly accurate")], pad=4, label="Стр. 1 статьи")
T2 = (110, 68, 502, 244)                                        # область таблицы на странице 8
crop("t2_big", 8, T2, [find(8, "Transformer (big)", 0)[0]], label="Таблица 2 статьи")
crop("fig3", 13, (116, 84, 506, 304), [word(13, "making")], rotate=90, label="Рисунок 3 статьи")
```
`find(page, text, idx=None)` → список прямоугольников найденного текста · `word(page, text, clip=None, n=0)` → прямоугольник отдельного слова · `words_in(page, clip)` · `U(rects)` → объединение · `crop(name, page, clip, highlights, rotate=0, pad=2.5, label="")`. Каждый элемент `highlights` — прямоугольник или список прямоугольников (тогда они объединяются в одну рамку).

Чтобы найти область рисунка или таблицы: `page.get_text("words")`, найти подпись «Figure N:» / «Table N:», взять область выше (рисунок) или ниже (таблица), отрендерить и **посмотреть глазами** (`build/crops/*.png`).

### Слоты под генерации и внешние кадры
Шот с полем `"media": {"kind": "gen" | "stock", "ru": "…", "prompt": "…"}` в `storyboard.json`:
- если есть файл `videos/<slug>/media/<shot_id>.mp4|mov|webm|png|jpg|webp` — он заполняет стейдж (cover, у картинок медленный наезд 1→1,08);
- если файла нет и в `shots.js` нет `SH.<id>` — рисуется заготовка `mediaSlot()`: тип, описание, промпт, длительность.

Шаг `media` (`media.py`, после `hero`) генерирует пустые слоты с английским `prompt` через HeyGen Video (`heygen-video-1`, text-to-video, кадр 1:1, длина — шот, округлённый вверх, от 5 с), все сразу, и кладёт клипы в `media/<shot_id>.mp4`. Нужен `HEYGEN_API_KEY`; без него остаются заготовки. `MEDIA_RES` (по умолчанию `768p`, лучше и втрое дороже — `1080p`), `MEDIA_MAX` — не больше стольких новых клипов за прогон (8). `media/heygen.json` помнит задания: повторный запуск подхватывает недоделанные без новой оплаты, смена промпта переделывает клип; файлы, положенные руками, шаг не трогает. Звук клипа отбрасывается.

После `render_stage.js` в папке видео появляются `media_slots.json` и `media_slots.md` — список слотов с таймингами и промптами для Flow. Положил файлы → `bash engine/build.sh videos/<slug> --from stage`.

## lib.js — компоненты для shots.js

Стейдж 1080×1000; **видимая зона после кадрирования — x 65–1015, y 96–1000**, всё важное держи в x 80–1000, y 120–980. Глобальные переменные в каждом шоте:
- `S` — данные шота: `S.dur`, `S.anchor` (время якоря от начала шота), `S.words` [{w, t0, t1}] (время от начала шота);
- `C` — кропы из `crops.json`; `tl` — таймлайн GSAP (на паузе, движок сам вызывает `seek`);
- `cam` — слой, который медленно наезжает (по умолчанию сюда кладётся всё); `hud` — неподвижный слой (кикер, рамки);
- `COL` — цвета текущей темы: bg, panel, line, ink, dim, blue, red, green, amber. **Других цветов в `shots.js` не пиши** — только `COL.*` и `opacity`; `D` = длительность; `ANC` = якорь − 0,1 с; `clampT(t)`.

| Функция | Что делает |
|---|---|
| `kicker('ТЕКСТ')` | в v8 ничего не рисует (оставлен для совместимости) |
| `txt(html, x, y, {size, font:'mono', w, color, italic, align:'l'|'r', ls, caps, parent})` | текст, `y` — центр строки |
| `el(tag, cls, css, html, parent)` | любой элемент; классы: `card` (HUD-карточка), `doc` (белая карточка), `tag` (плашка-статус), `hl` / `hl red` (рамка подсветки) |
| `appear(e, t, {dy, d, ease, op})` | появление: снизу на 40 px + прозрачность + размытие 8→0, expo.out |
| `show(e, t, op)` | мгновенно показать |
| `wt('слово', n)` | время n-го вхождения слова в шоте (или null) — привязка к речи |
| `docCard(cropName, {cx, cy, maxW, maxH, bleed, hlAt, hlStagger, color:'red', zoom:[1,1.08], focus:0|'all', label, frame})` | кроп статьи **без рамки** (v8): картинка вписывается в `maxW×maxH`, увеличенные в `bleed` раз (по умолчанию 1,2), и может выходить за края кадра; в светлой теме белый фон бумаги сливается с фоном. «Прожектор» на подсветке в момент `hlAt`, наезд по умолчанию 1→1,08 на всю картинку. `frame: true` — старая белая карточка |
| `bigNum(chars, x, y, {size, color, glow, at, step})` | крупное число, символы появляются по одному. `chars` — строки или объекты `{t, size, color, mono, ml}` |
| `wordCard(text, x, y, {w, h, size, dimText})` + `activate(card, t, color)` | карточка-слово и её подсветка рамкой |
| `wordGraph(words, cx, cy, r, {ry, fs, nh})` + `edge(g.edgesG, g.pos[i], g.pos[j], {w, op, color})` | слова по кругу и связи |
| `svgLayer()`, `sv(svg, tag, attrs)`, `drawOn(path, t, d)`, `arrowHead(svg, path, color)` | SVG: линии и стрелки, которые «рисуются» |
| `srcLabel(text, x, y)` | мелкая подпись моноширинным 18 px (для внешних фактов; под кропами статьи не нужна) |
| `rel(el)` | координаты элемента на стейдже (для стрелок между элементами) |

Шаблон шота:
```js
SH.s15_3 = () => {
  bigNum(['2', '8', ',', '4'], 540, 480, { size: 260, color: COL.blue, at: ANC });
  const c = txt('BLEU · АНГЛ.–НЕМ. · WMT 2014', 540, 640, { font: 'mono', size: 26, color: COL.dim, ls: '.15em' });
  appear(c, ANC + 0.2);
};
```
Нужен компонент, которого нет, — напиши функцию в начале своего `shots.js`. **`engine/` не меняй**: параллельно с тобой могут собираться другие ролики. Предложения по движку — в отчёт.

## Уроки, на которых уже обожглись
- Кадровые границы движок считает сам (`round(t*30)`), рассинхрона нет — не пересчитывай вручную.
- Fira и JetBrains Mono с греческим; символы `→ ≈ ≤ ≥ ☉ ⊙ ± √ ∞` подставляются из запасного шрифта Noto Sans Math. Если `render_stage.js` пишет `!! glyphs missing` — символа нет нигде: нарисуй SVG. Степени — `<sup>`.
- Кропы без рамок могут выходить за край — это нормально, но подсвеченное место (`focus`) должно оставаться в видимой зоне. Текст статьи на экране — не меньше ~28 px: режь узко.
- Верх стейджа (y < 96) и края по 65 px отрезаются при кадрировании — не ставь туда ничего.
- Подписи на экране — тоже факты: проверяй их по статье, как текст диктора.
- Рисунки, напечатанные боком, — `rotate=90` в `crop`.
- Если `tts.py` пишет `ERRORS`, сборка остановится: акцентное слово или якорь не найдены в тексте сцены, или доли шотов не дают 1.

### Аватар (шаг `avatar`)

`audio.py` пишет `build/voice16k.wav` — только голос, 16 кГц моно, по таймлайну ролика. `avatar.py` отправляет его с портретом в сервис FlashHead (`services/flashhead_avatar`, `POST /v1/avatar`) и кладёт ответ в `avatar.mp4` папки видео; `compose.py` ставит его под стейдж вместо заглушки. Нужны `FLASHHEAD_URL` (из контейнера: `http://host.docker.internal:18195` с `--add-host host.docker.internal:host-gateway`) и `AVATAR_IMAGE` (портрет анфас, рот закрыт). `avatar.json` помнит хэши голоса и портрета: тот же голос второй раз не считается. Без переменных остаётся заглушка.
